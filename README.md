# EditSharp

A C# library for timeline video editing. A clip is a node graph fed by pluggable sources (media files, text, colour, noise, tones, nested timelines); playback and export run through ffmpeg and a GPU compositor.

- Package: `dotnet add package EditSharp`
- API reference: https://coolbeansstudioofficial.github.io/EditSharp/
